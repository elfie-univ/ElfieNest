## 一、设计目标与核心约束

### 1.1 设计目标

| 目标 | 说明 |
|------|------|
| **快速响应** | 情绪响应必须比大模型快（毫秒级 vs 秒级） |
| **条件反射** | 情绪是条件反射性的，不经过思考，直接触发 |
| **多源融合** | 支持多种输入源，融合去重，避免重复计算 |
| **差异化处理** | 不同强度的刺激产生不同的情绪增量 |

### 1.2 核心约束

```
约束1: 情绪 ≠ 思考
       情绪是边缘系统的化学反应，比大脑皮层快100倍

约束2: 情绪强度 ≠ 情绪类型
       同样是"恐惧"，看到小狗和看到恐龙的强度完全不同

约束3: 情绪累积 ≠ 线性叠加
       饱和增长：值越高，增长越慢（避免无限增长）

约束4: 情绪衰减 ≠ 均速下降
       分阶段衰减：高值快消散，低值慢残留（情绪残留效应）
```

## 四、强度识别机制

### 4.1 为什么需要强度？

```
场景1: 被轻轻批评
场景2: 被狠狠骂

如果只识别情绪类型：
  输入1 → sadness +20
  输入2 → sadness +20
  结果：一样！❌ 不合理

引入强度后：
  输入1 → sadness, intensity=0.2 → 实际增量 = 20 * 0.2 = 4
  输入2 → sadness, intensity=0.9 → 实际增量 = 20 * 0.9 = 18
  结果：相差4.5倍！✅ 符合真实感受
```

### 4.2 人类如何识别强度？

| 维度 | 轻轻批评 | 狠狠骂 |
|------|---------|--------|
| **音量** | 正常/低沉 | 大声/咆哮 |
| **语速** | 平稳 | 急促 |
| **语调** | 平和 | 尖锐 |
| **表情** | 严肃 | 愤怒、瞪眼 |
| **词汇** | "这个不太好" | "你个废物！" |
| **持续时间** | 短 | 长 |

**人类是多维度综合判断，不是单一关键词！**

### 4.3 各输入源的强度计算

#### 4.3.1 文本强度（关键词库 + 修饰词）

```python
# 词汇强度库
WORD_INTENSITY = {
    # 批评类
    "不太好": 0.2,
    "批评": 0.4,
    "责备": 0.5,
    "骂": 0.7,
    "废物": 0.9,
    "滚": 0.95,
    
    # 夸奖类
    "不错": 0.3,
    "好": 0.4,
    "很棒": 0.6,
    "太厉害了": 0.8,
    "天才": 0.9,
}

# 修饰词增强/减弱
MODIFIERS = {
    "有点": 0.5,      # 减弱
    "稍微": 0.6,
    "非常": 1.3,      # 增强
    "特别": 1.4,
    "超级": 1.5,
}

def keyword_intensity(text: str) -> float:
    """从文本计算强度"""
    base_intensity = 0.3  # 默认
    
    # 找关键词
    for word, intensity in WORD_INTENSITY.items():
        if word in text:
            base_intensity = intensity
            break
    
    # 检查修饰词
    for modifier, factor in MODIFIERS.items():
        if modifier in text:
            base_intensity *= factor
    
    return min(base_intensity, 1.0)

# 示例:
# "这个不太好" → 0.2
# "批评你" → 0.4
# "非常生气地骂" → 0.7 * 1.3 = 0.91
```

#### 4.3.2 图像强度（DeepFace）

```python
from deepface import DeepFace

def image_emotion_intensity(image_path: str) -> tuple[str, float]:
    """从图像识别情绪和强度"""
    
    result = DeepFace.analyze(
        img_path=image_path,
        actions=['emotion']
    )[0]
    
    emotion_raw = result['dominant_emotion']  # 'happy', 'angry', etc.
    intensity = result['emotion'][emotion_raw]  # 0-1
    
    # 映射到我们的情绪体系
    emotion_map = {
        'happy': 'happiness',
        'sad': 'sadness',
        'angry': 'anger',
        'fear': 'fear',
        'surprise': 'surprise',
        'disgust': 'disgust',
        'neutral': 'calm',
    }
    
    return emotion_map[emotion_raw], intensity
```

#### 4.3.3 语音强度（特征分析）

```python
import librosa
import numpy as np

def audio_emotion_intensity(audio_path: str) -> tuple[str, float]:
    """从语音识别情绪和强度"""
    
    y, sr = librosa.load(audio_path, duration=5.0)
    
    # 提取特征
    energy = np.mean(librosa.feature.rms(y=y))
    pitch = np.mean(librosa.yin(y, fmin=50, fmax=500))
    pitch_std = np.std(librosa.yin(y, fmin=50, fmax=500))
    
    # 规则判断
    if energy > 0.1 and pitch_std > 50:
        # 高能量 + 高音高变化 → 愤怒
        return 'anger', 0.7
    elif energy < 0.03:
        # 低能量 → 悲伤
        return 'sadness', 0.5
    else:
        # 正常 → 平静
        return 'calm', 0.3
```

#### 4.3.4 物理事件强度（直接映射）

```python
def physical_event_intensity(event: dict) -> tuple[str, float]:
    """从物理事件识别情绪和强度"""
    
    event_type = event['type']
    
    if event_type == 'collision':
        # 碰撞事件
        force = event['force']  # 物理引擎给出
        intensity = min(force / 10.0, 1.0)  # 归一化
        return 'fear', intensity
    
    elif event_type == 'pet':
        # 抚摸事件
        pressure = event['pressure']
        intensity = min(pressure / 5.0, 1.0)
        return 'happiness', intensity
    
    elif event_type == 'fall':
        # 跌落事件
        height = event['height']
        intensity = min(height / 3.0, 1.0)
        return 'fear', intensity
```

## 六、情绪累积与衰减公式

### 6.1 饱和增长公式

```
增量 = base_delta × intensity × accumulate_rate × saturation

其中:
- base_delta: 情绪类型的基础增量（如 fear_base=40）
- intensity: 输入携带的强度 (0.0-1.0)
- accumulate_rate: 积累率（性格相关，默认0.5）
- saturation: 饱和因子 = (1 - value/max_value)

特点:
- 值越高，增长越慢（避免无限增长）
- 强度越高，增量越大
- 性格影响积累速度
```

**示例:**

```
场景: 恐惧情绪，当前值=30，最大值=100

输入1: intensity=0.2（轻）
  增量 = 40 × 0.2 × 0.5 × (1 - 30/100) = 40 × 0.2 × 0.5 × 0.7 = 2.8
  新值 = 30 + 2.8 = 32.8

输入2: intensity=0.9（重）
  增量 = 40 × 0.9 × 0.5 × (1 - 30/100) = 40 × 0.9 × 0.5 × 0.7 = 12.6
  新值 = 30 + 12.6 = 42.6

相差 4.5 倍！
```

### 6.2 分阶段衰减公式

```
衰减策略: 分阶段指数衰减

高值区 (value > 30):
  半衰期 = base_half_life × 0.3  （快速衰减）
  
低值区 (value ≤ 30):
  半衰期 = base_half_life × 3    （残留期，慢衰减）

特点:
- 高值情绪快速消散（如暴怒很快平息）
- 低值情绪缓慢残留（如淡淡的忧伤持续很久）
- 符合人类情绪消散的真实体验
```

**示例:**

```
场景: 愤怒情绪，base_half_life=60秒

高值区 (value=80):
  实际半衰期 = 60 × 0.3 = 18秒
  18秒后: value = 40
  
低值区 (value=20):
  实际半衰期 = 60 × 3 = 180秒
  180秒后: value = 10

解释: 强烈的愤怒快速平息，但残留的怒意持续很久
```

### 6.3 频率慢化机制

```
问题: 连续看到恐惧事件，恐惧应该消散得更慢

解决: 维护最近输入的频率，频率越高，衰减越慢

频率慢化因子:
  slow_factor = 1 + recent_count × 0.5

其中:
- recent_count: 最近时间窗口内的输入次数
- 0.5: 慢化系数

示例:
  最近1次输入: slow_factor = 1 + 1×0.5 = 1.5 （衰减慢1.5倍）
  最近3次输入: slow_factor = 1 + 3×0.5 = 2.5 （衰减慢2.5倍）
```

## 七、频率信息维护

### 7.1 数据结构

```python
from collections import deque
from dataclasses import dataclass

@dataclass
class EmotionState:
    """单个情绪的状态"""
    
    value: float                    # 当前值 (0-100)
    profile: dict                   # 情绪配置
    expire_times: deque = None      # 每个输入的过期时间
    
    def __post_init__(self):
        if self.expire_times is None:
            self.expire_times = deque()
    
    @property
    def window_size(self) -> float:
        """时间窗口大小（秒）"""
        return self.profile.get('window_size', 60.0)
```

### 7.2 频率维护算法

```python
def clean_expired(self, current_time: float):
    """清理过期的输入记录"""
    while self.expire_times and self.expire_times[0] < current_time:
        self.expire_times.popleft()

def get_recent_count(self, current_time: float) -> int:
    """获取最近时间窗口内的输入次数"""
    self.clean_expired(current_time)
    return len(self.expire_times)

def record_input(self, current_time: float):
    """记录一次输入"""
    expire_time = current_time + self.window_size
    self.expire_times.append(expire_time)
```

## 八、融合去重机制

### 8.1 问题场景

```
事件: 主人狠狠骂了精灵

可能产生多个输入:
  输入1 (关键词): emotion=sadness, intensity=0.7
  输入2 (音调):   emotion=sadness, intensity=0.8
  输入3 (大模型): emotion=sadness, intensity=0.85

问题:
  如果都累加 → sadness 增量 × 3 → 不合理！
  同一个事件，不应该重复计算
```

### 8.2 去重策略

```python
class EmotionSystem:
    """情绪系统"""
    
    def __init__(self):
        self.processed_events = set()  # 已处理的事件ID
        self.cache_ttl = 5.0           # 缓存过期时间
    
    def process_input(self, input: EmotionInput) -> bool:
        """处理情绪输入，返回是否处理成功"""
        
        # 检查是否已处理
        if input.event_id in self.processed_events:
            return False  # 去重
        
        # 记录已处理
        self.processed_events.add(input.event_id)
        
        # 累积情绪
        self._accumulate(input)
        
        return True
```

### 8.3 强度融合策略

```python
def fuse_intensities(inputs: list[EmotionInput]) -> float:
    """融合多个输入源的强度"""
    
    # 策略1: 取最大值（最敏感）
    # return max(i.intensity for i in inputs)
    
    # 策略2: 加权平均（更稳定）
    weights = {
        'physical': 1.0,   # 物理事件最可信
        'audio': 0.8,
        'image': 0.7,
        'text': 0.5,       # 文本最不可信
        'brain': 0.9,
    }
    
    total = sum(i.intensity * weights[i.source] for i in inputs)
    weight_sum = sum(weights[i.source] for i in inputs)
    
    return total / weight_sum
```

```
问题: 不同性格的情绪反应不同

  neuroticism (情绪不稳定性)
    → 高: 情绪阈值低，衰减慢，易波动

  agreeableness (宜人性)
    → 高: 愤怒阈值高，依恋增长快
    → 低: 愤怒阈值低，依恋增长慢

设计方向:
  accumulate_rate = base_rate × personality_modifier
  decay_rate = base_decay × personality_modifier
```

问题: 情绪需要外化为可见的表达

映射维度:
  1. 表情: 情绪 → 面部表情参数
  2. 动作: 情绪 → 肢体动作

## 十二、总结

### 核心设计要点

| 要点 | 说明 |
|------|------|
| **快速响应** | 本地小模型，毫秒级响应 |
| **强度识别** | 多维度综合判断，不是单一关键词 |
| **饱和增长** | 值越高增长越慢，避免无限增长 |
| **分阶段衰减** | 高值快消散，低值慢残留 |
| **频率慢化** | 连续刺激延缓衰减 |
| **融合去重** | 同一事件不重复计算 |

### 技术栈

| 组件 | 技术 |
|------|------|
| 文本检测 | Erlangshen-RoBERTa (transformers) |
| 图像检测 | DeepFace |
| 语音检测 | pyworld + librosa |
| 数据结构 | dataclass + deque |
| 测试 | pytest |
