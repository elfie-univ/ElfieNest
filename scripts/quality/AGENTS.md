# 脚本质量执行规则

本目录实现仓库级单项检查、验证选择与复用、以及受管 Git Hook。它执行
`scripts/governance/` 定义的规则，但不能改写契约、放宽边界或成为第二个产品入口。

- `checks/` 每个文件只实现一种可独立诊断的检查；不得偷偷启动服务、浏览器或重复执行
  其他检查。
- `validation/` 负责按候选路径选择、聚合和复用证据；精确测试节点不能冒充更大测试包，
  失败、阻塞和实时外部观察不能缓存为通过。PR 前候选证据必须同时绑定候选 SHA、基础
  治理指纹、Manifest、候选工具链与受信任 Workflow 身份；任一不匹配就运行正常选中图。
- `hooks/` 只安装快速 staged pre-commit 门禁；不得添加 fetch、push、全仓测试、Godot
  启动或其他网络操作。
- 目录中的可执行规则属于治理变更，必须与产品实现放在职责清晰的本地 commit 中，并由
  不可变基础提交中的分类器判断完整候选；只要产品仍通过基础规则，最终可以使用一个 PR。
- 本目录不提供对外稳定的叶子路径。贡献者优先使用 `scripts/pre_submit_gate.sh`、
  `scripts/bootstrap.sh` 和公开文档中的高层入口。
