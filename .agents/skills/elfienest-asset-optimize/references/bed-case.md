# 床桌椅套装历史方法

这是一次已发生的案例，不是任意资产都能复用的固定压缩率，也不是当前所有模型的基准。

## 已核对证据

2026-10-16 读取历史 `optimize.py`、`verify.cjs` 和 `verification.json`，并对源文件、存储候选和最终候选重新计算 SHA-256；未重跑会写模型的历史脚本。
当时的目录为 `build/asset_previews/elfie_furniture_v13_reference_match_plain_optimized_v1/`。
这些本地历史文件可能不随新环境保留，本技能的操作原则不依赖该目录存在。

## 可以复用的机制

存储阶段：只保留有效缓冲；按材质使用情况去掉未使用 UV（该次 548,552 字节）；
在已知不透明且顶点 alpha 全为 1 的部件上去掉恒定 alpha（172,548 字节）；
适用的 primitive 用 UINT16 存索引，保持数值不变；保留所有内嵌图片的原编码字节。
因此，该次没有靠压缩图片或减少 draw call 获得收益。

减面阶段：Blender 局部 Decimate；按完整角点属性重建索引，保留法线与 UV 缝；
按确定性双向最近表面距离和包围盒误差检查，超过限值则提高保留比例或回退原几何。
床体、床垫、被子、枕头与椅子分别处理；灯、抽屉、桌柜、地毯保持原几何；搭毯流苏单独保护。
原脚本按该模型固定数组区间识别流苏，不能作为通用部件识别方法。

## 该次验证的实际含义

记录包含存储阶段索引/保留属性等价、材质/内嵌图片原字节保留、部件归属与变换保留、
无退化三角面、被子与床垫/搭毯接触间隙，以及独立导出部件的一致性。
查看器在相同预设与日间光照下比较全貌和床体近景，未发现明显外观变化。

但减面结果的像素并不完全一致：床体截图平均通道差约 0.645/255，
全套约 0.350/255；超过 8/255 差异的像素分别约 1.44% 和 0.77%。
这些数值只是该次相机、截图及采样的观测结果，不是可迁移的通过阈值。
记录没有证明帧率或加载时间改善，不能用文件减小 50.22% 推导“运行快一倍”。
