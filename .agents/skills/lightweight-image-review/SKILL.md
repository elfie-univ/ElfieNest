# 轻量读图

这是 ElfieNest 项目级技能。使用当前 checkout 的 `.agents/skills/lightweight-image-review/` 内脚本，不依赖用户级技能副本或固定电脑路径。

控制的是**新增图片输入**，不会删除已进入上下文的图片，也不是配置层的强制限额。无需用户每轮批准正常的预览和局部检查；用户指定原图、精确色彩或像素检查时优先满足该要求并如实说明开销。

## 操作

使用已有 Pillow 环境运行 [scripts/image_preview.py](scripts/image_preview.py)。在要求受控 Python 的仓库中使用该仓库解释器；不要为本技能安装依赖或修改环境。没有可用环境时先读文件元数据，说明限制。

```sh
/合适的/python3 /技能绝对路径/scripts/image_preview.py inspect /图片绝对路径1 /图片绝对路径2
/合适的/python3 /技能绝对路径/scripts/image_preview.py preview /图片绝对路径1 /图片绝对路径2 --out /独立输出目录/overview.jpg
/合适的/python3 /技能绝对路径/scripts/image_preview.py preview /单张图片绝对路径 --crop 左 上 右 下 --out /独立输出目录/detail.jpg
```

- inspect 只输出尺寸、格式、字节数和 SHA-256；先据此识别重复文件和同一图片的放大版本。不要为了列目录或查尺寸先打开所有像素。
- 首轮通常只向模型发送一张总览；多图用标有序号的缩略拼图，文字 JSON 保留序号到文件的对应关系。不要在同轮发送拼图和全部原图。
- 脚本默认长边至多 1536、JPEG 质量 82、不放大，并将预览编码文件限制在 1.4 MB 内（Base64 后约 1.87 MB）。按每次新增图片输入**合计约 2 MB**控制，通常只看一张，必要时两张。先检查输出 JSON 中的 data_url_bytes_estimate，再调用图片查看工具。
- 局部检查按原图经 EXIF 校正后的坐标裁剪，保留原生细节，不插值放大。不要同时发送同一区域的小图和四倍放大版。尽量复用已经看过的图和结论，不机械重读。
- 总览只判断构图、形态和明显差异；小字、眼睑、拓扑等细节另取局部。JPEG 为有损预览，透明区域使用白色背景；精确颜色、透明度、像素边缘和最终设计验收需要相应原图/无损局部，不能仅凭预览宣称通过。
- 所有派生图写到独立临时目录、会话可视化目录，或仓库规则允许的 build 目录。原文件只读；不覆盖已有输出，不修改来源目录、源素材、配置、对话历史或模型档位。仅返回路径链接不会加载像素，只有需要判断时才调用 view_image。

## 累积与验证

- 分阶段保存短结论和文件路径到当前回复；默认不另建台账。后续需要原图时按需读取，不把旧图整批再注入。
- 已有图片负担影响响应时，说明当前累积，按用户授权压缩或使用 worktree-fresh-chat；不自动创建/清空/归档对话。不能保证 compact 会移除旧图。
- 验证至少包含真实样本的原图哈希不变、预览实际字节/尺寸、一次总览和必要局部的实际目视检查。分别报告图片载荷缩减与视觉可用性；没有受控对照，不声称端到端提速百分比，也不声称修好了传输断线。
