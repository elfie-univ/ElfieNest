# ElfieNest Web 设计系统

## 1. 氛围与识别

ElfieNest 是温暖、安静的 Owner 管理台：纸张感表面、克制的土色强调和紧凑但易读的运营信息。识别点是“巢穴账本”般的材质感，而不是通用 SaaS 面板。

## 2. 颜色

当前色板由 `:root[data-theme]` 选择。默认是 `warm-paper`，另有 `harbor-blue`、`orchid-archive`、`moss-green`，它们共享同一套语义角色。组件只能使用语义 token，不能在页面里新增局部颜色。

| 角色 | 现有 token | shadcn 语义 token | 用途 |
| --- | --- | --- | --- |
| 画布 | `--page-bg` | `--background` | 页面背景 |
| 抬升表面 | `--surface-raised` | `--card`、`--popover` | 卡片与弹窗 |
| 字段表面 | `--surface-field` | `--secondary` | 输入与次级控件 |
| 主文字 | `--text` | `--foreground` | 正文 |
| 次文字 | `--text-muted` | `--muted-foreground` | 标签与元数据 |
| 品牌动作 | `--accent` | `--primary` | 主按钮与选中态 |
| 轻量动作 | `--surface-hover` | `--accent` | hover、安静按钮 |
| 分隔线 | `--border` | `--border`、`--input` | 边界与输入框 |
| 键盘焦点 | `--focus-ring` | `--ring` | 焦点提示 |
| 错误 | `--error-text` | `--destructive` | 危险动作与错误 |

## 3. 字体

使用 `Noto Serif SC`、`Songti SC` 和 serif 兜底以保留编辑感；等宽字体只用于 JSON 和机器值。12px 只用于非关键信息标注，标签与辅助文字为 14px，正文和身份值为 16px，卡片标题为 18px，分区标题为 22px，展示标题为 32–48px。运营卡片标签不得小于 14px；需对齐的数字使用等宽数字。
管理卡片、字段行、状态标签、表格单元格和侧栏动作中的所有可见运营文字都有 14px 下限；只有装饰性说明或非运营元数据可以使用 12px。

## 4. 间距与布局

基础单位为 4px，常用间距为 4、8、12、16、20、24、32、40、48、64px。产品壳使用 `fixed-sidenav-shell` 原语：侧栏固定在视口高度的工作台内，主内容区是唯一的主滚动容器；当导航列表超过侧栏高度时，只有侧栏自己的导航列表可以滚动。760px 以下网格折为一个可读列，控件可以换行但主内容不能横向溢出。

## 5. 组件

### shadcn Button
- **结构：** 使用 shadcn 生成的原生按钮基础件。
- **变体：** default、secondary、outline、ghost、destructive、纯图标。
- **状态：** hover、按下、focus-visible、disabled、loading。
- **无障碍：** 原生 button、键盘触发、可见焦点环。
- **尺寸：** 应用默认高度 40px、水平内边距 16px；紧凑尺寸和纯图标只用于高密度工具栏。
- **颜色：** 主按钮 hover 保持深色品牌底上的浅色文字；outline 静止态使用字段底色和强边框，确保一眼能识别为按钮；outline、ghost hover 使用浅色表面和普通前景文字。
- **动作层级：** 页面级刷新统一使用带刷新图标的品牌色实心按钮；outline 只用于取消、查看、验证等更低优先级选择。

### shadcn Input 与数字步进器
- **结构：** 生成的 input 放在一个完整边框的递减、编辑、递增控件组中。
- **状态：** 默认、hover、focus-within、错误、禁用。
- **无障碍：** 标签关联、说明文本、边界禁用。
- **形态：** 数字步进器是一个 40px 高的完整外框，内部只用直角分隔线；按钮与输入框不得各自出现外边框或圆角。

### 字段行
- **结构：** 可见设置与表单字段在所有宽度下使用左侧标签、右侧控件的字段行。标签列放字段名和可选说明；控件列承载输入框、Select、开关和校验反馈。
- **响应式：** 真正的产品字段在桌面、平板和 375px 手机宽度下都保持左侧标签、右侧控件；760px 断点不能把标签堆到控件上方。长标签、中文文本、字段值和校验反馈都在各自列内换行，不能截断或造成页面横向溢出。
- **无障碍：** 可见标签、说明、错误状态和控件保持程序化关联。

### shadcn Checkbox 与分组 Select
- **结构：** 使用 shadcn 提供、底层由 Radix 支持的可访问控件。
- **状态：** 默认、hover、选中、focus-visible、禁用。
- **无障碍：** 标签关联、键盘选择、portal 内焦点安全。
- **分组 Select：** 带分类的选项集合使用带标签的 Select group 和分隔线，不使用重复的独立 Select 或临时原生下拉框。

### shadcn Dialog 与 Alert Dialog
- **结构：** 使用 Radix 支持的 overlay、content、heading、description 和动作区。
- **状态：** 打开、关闭、取消、确认、处理中。
- **无障碍：** 焦点圈定、标题/描述关联、关闭后焦点返回触发器。

### shadcn Table
- **结构：** 表格数据使用 shadcn Table 原语承载 header、body、row、head 和 cell。
- **状态：** 默认、行 hover、可选行选中、空状态、加载和错误。
- **无障碍：** 使用原生 table 语义、表头关联、运营文字不小于 14px；新的表格工作不再使用伪表格 grid。

### 管理侧栏
- **结构：** 固定侧栏保留 logo 和唯一的 `ELFIE NEST` 品牌文字；不显示 `OWNER CONSOLE` 等控制台副标题。
- **尺寸：** 桌面和紧凑侧栏中，每个导航、快捷动作和紧凑账号目标都严格为 48px 高；当前路由保留 `aria-current="page"`。
- **分组：** 导航分组使用语义 group 标签；可见分组标题和分隔线保持紧凑，让侧栏读作一个控制面。
- **状态：** 默认、hover、focus-visible、active 和按下状态只使用现有语义 token。

### 身份卡片
- **结构：** 使用可复用的 shadcn Card 外壳，左侧固定方形头像，右侧使用横向 `标签：值` 网格。
- **尺寸：** 桌面头像统一为 104px 方形，窄屏为 64px 方形；用户卡与精灵卡共享头像几何和字号层级。
- **字体：** 标签 14px、值 16px；长 ID 和简介可以横跨整行，但不回退为标题在上、内容在下。
- **状态：** 在线、生命周期等状态使用语义圆点加文字成对呈现；只有圆点不足以表达状态。
- **内联编辑：** 简单身份编辑留在卡片或账号面板内部，把展示值替换为同一行内的已标注控件和保存/取消动作；多字段或破坏性决策才使用弹窗。

## 6. 动效与交互

控件在 140–200ms 内变化颜色、边框、阴影、透明度和 transform；按下可轻微缩放。遵守 `prefers-reduced-motion`，不添加无意义动效。

## 7. 层次与表面

采用混合层次：卡片和输入框使用安静的 1px 染色边框，内嵌控件用色调区分，只有弹窗和菜单使用现有的染色浮层阴影。默认不使用重阴影和胶囊形。

## 8. 无障碍约束与已接受债务

目标 WCAG 2.2 AA：每个控件都有可见焦点、键盘操作和适应当前主题的文字对比度。当前已接受债务：模型、粮食和运行目录数据中的旧原生表格或伪表格表面，保留到各自范围内的 shadcn Table 迁移任务；侧栏、字段行、状态和身份卡片没有已接受视觉债务。

## 9. 双语界面契约

双语界面只扩展现有 warm-paper 设计语言，不为英文新增第二套布局、色板或组件。`zh-CN` 与 `en-US` 共用同一套语义 token、间距、信息架构和响应式产品壳。

### 语言切换器

- **结构：** 使用唯一共享、带可见标签的 `LanguageSwitcher`，由现有 `SelectField` 与 shadcn/Radix Select 原语组成。它包含一个可见标签、一个 trigger，以及 portal 中的 listbox；选项严格为两个，并使用语言自称：`简体中文`、`English`。
- **位置：** 登录、Setup 与账号菜单可以把共享控件放入各自已有动作区，但不得改变导航层级，也不得维护页面自己的语言状态。
- **状态：** default、hover、focus-visible、expanded、selected、disabled 全部使用现有语义 token。列表打开时当前语言保持选中；切换后焦点留在 trigger，URL、滚动、表单、弹窗与应用业务状态均不重置。
- **键盘：** Tab 按文档顺序到达 trigger；Enter 或 Space 打开；方向键移动选项；Enter 确认；Escape 关闭且不改值；Tab 关闭并继续。trigger 与 portal 选项始终保留可见 `--focus-ring`，无障碍名称跟随周边界面语言。

### 字符、元数据与英文膨胀

- `--font-sans` 继续作为唯一 UI 字体所有者。fallback 必须让 Latin 文字落到 `Noto Serif` 或 `Noto Serif SC` 的 Latin 字形，让 CJK 落到 `Noto Serif SC`、`Songti SC`，最后使用通用 `serif`。组件不得新增局部语言字体栈；等宽字体仍只用于机器值。
- 文档根节点是元数据权威，必须同步更新为 `lang="zh-CN"` 或 `lang="en-US"`；两个支持语言都使用 `dir="ltr"`。portal 继承当前文档语言和方向。组件不得从已渲染文本猜测语言，也不得持有相互竞争的 `lang` 状态。
- 英文 UI 文案按至少比中文标签膨胀 30% 设计。按钮和字段行可以增高或换行；使用 `min-width: 0`、内在尺寸与自然换行，不使用按中文长度固定的宽度。若省略会隐藏动作或必要含义，运营标签与说明不得使用 ellipsis。
- 用户内容、ID、model/provider 名称、JSON 与其他机器值不翻译；它们在自己的区域内换行，且不改变双语 UI 字体契约。

### 响应式与无障碍验收

- 两种语言都在 375px、768px、1280px 验收，并在窄屏与桌面宽度追加 200% zoom reflow。切换语言不得造成控件裁切、文字重叠、焦点提示隐藏或键盘焦点丢失。
- 文档与主产品壳禁止出现页面级水平滚动。长英文与 CJK 文本在现有 grid/flex 所有者内换行，可收缩子项使用 `min-width: 0`。Monitor 工具栏或数据表等明确的局部滚动区仍可在自身边界内滚动，但不得使 `html`、`body` 或应用根节点宽于视口。
- 纯键盘验收覆盖：打开语言选择、确认切换、用 Escape 取消、用 Tab 继续，以及切换后继续操作周边页面。两种语言的焦点顺序、焦点返回与 focus-visible 样式必须等价。
