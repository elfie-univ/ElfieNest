# Setup Feature 规则

Setup 是首次安装的受限产品流程，不是模型、账户或系统配置的第二事实源。

- 使用与 Admin 相同的 Provider/模型/配置 Feature 和 Adapter，只提供安装所需的最小
  投影；检测、扫描、推荐、下载和保存算法不能复制。
- Ollama 检测、本地模型扫描和机器配置采集通过 Port；Feature 不调用系统命令、SDK、
  文件路径或具体 Infrastructure。
- Setup Principal 具有可过期的最小权限，不能访问完整管理员、用户或 Runtime
  authority 能力。
- 硬件感知模型推荐使用可版本化候选配置和可测试决策输入；在该 Feature 单独获批前，
  不把固定实验结论写成架构规则。
- 完成 Setup 后只写入权威配置，不保留第二份安装状态或兼容副本。
