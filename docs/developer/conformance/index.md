# Conformance registers

Conformance registers are temporary migration ledgers. They describe exact
known gaps against a contract and the evidence required to remove them. They
never redefine the target or authorize new debt. A register is deleted when
its machine baseline is empty and every recorded gap is closed.

The registered System, App, Model/Food/Tool, Brain and Nest–Godot debt has
reached zero, so those temporary registers and empty baselines were removed.
The Brain and Nest–Godot contracts are now enforced directly by permanent
architecture and focused runtime tests. The remaining register is the active
Elfie 2.0 life-system work:
