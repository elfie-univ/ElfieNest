# Elfaria 世界知识体系框架 v0.1

> 状态：框架基线，已确认结构；本文定义“必须描述哪些方面”，不填充具体世界内容。
> 具体事实仍以版本化 World Canon 为准。

## 1. 目标与边界

本框架只解决一个问题：如何完整、结构化地描述 Elfaria，避免遗漏基础规律、空间关系、社会运行和知识边界。

它不是某一只 Elfie 的传记，也不是 Profile、Selfhood 或 Memory 的存储设计。个体初始化是从本框架及其具体 Canon 内容派生出的下游结果。

## 2. 九个世界知识领域

| 领域 | 必须描述的方向 |
| --- | --- |
| 1. 宇宙与自然规律 | 时间、物理、能量、光照、季节、自然现象及生命共同规律 |
| 2. 星球环境、生态与地图 | 星球环境、生态、地貌、区域层级、地图边界和区域之间的关系 |
| 3. 物种、身体与生命周期 | 三种物种的共同特征与差异、身体、感知、需求、成长和生命周期 |
| 4. 精灵镇、设施与生活空间 | 精灵镇地图、区域和居住区、物种分布、公共设施、路径、活动范围及空间关系 |
| 5. 社会结构、治理与关系规则 | 家庭、群体、长老、责任、决策、信任、冲突、合作和社会身份 |
| 6. 经济、技术与基础设施 | 资源、生产、劳动、交换、交通、能源、工具和技术水平 |
| 7. 文化、语言与日常生活 | 语言、食物、服饰、习俗、仪式、教育、娱乐、价值观和日常节奏 |
| 8. 历史、重要事件与地球关系 | 历史阶段、关键事件、集体记忆、跨世界接触、赴地计划和地球关系 |
| 9. 知识分层、信息边界与观测限制 | 普通知识、部分群体知识、专业知识、个人知识、未知范围和不可观测事实 |

### 精灵镇地图是第四领域的核心组成

“精灵镇”不只是一个地点名称，而是一套可被引用的空间模型。其框架必须能够承载：

- 镇的整体边界与区域层级；
- 各物种居住区及其相互位置；
- 公共设施、学习场所、生活场所和赴地相关设施；
- 居住点、公共空间、道路或路径之间的关系；
- 精灵通常能到达、熟悉或无法到达的活动范围；
- 聚落稀疏、个体彼此不必认识的空间和社会原因。

地图事实应与文化、历史、物种分布和个人经历共享同一套地点标识，故事不得临时创造未登记地点来填空。

## 3. 五条横向约束

这些不是额外的世界领域，而是所有领域都必须遵守的共同规则：

1. **层级范围**：宇宙 → 星球 → 区域 → 精灵镇 → 地点 → 个体。
2. **时间与因果**：区分事件发生时间、生命阶段和当前写入时间；重要事实要能解释生活、选择或结果。
3. **知识权限**：世界中存在的事实，不等于每只 Elfie 都学会；个体只获得其经历和学习范围内的知识。
4. **来源与版本**：事实必须有稳定标识、来源、版本、范围和确定性，能够被追溯。
5. **未知与观测边界**：没有真实观测或 Canon 依据的内容保持未知，不生成实时巢内活动、天气、位置或动作。

## 4. 框架与具体内容的关系

```text
九个领域（必须描述什么）
        ↓ 填充经过审阅的 Canon 内容
Elfaria 世界知识体系
        ↓ Genesis 按个体经历选择
个人知识、经历、关系、Selfhood 与 Profile
```

同一条世界事实可以被多个故事引用，但只能有一个 Canon 来源。个人故事可以解释和体验世界事实，不能反过来改写世界规则。

## 5. 本框架的冻结标准

- 九个领域保持不再拆分为新的一级类别；
- 精灵镇地图明确属于第四领域，而不是独立的平行体系；
- 个人知识、个人故事、关系、Profile 和 Selfhood 不混入世界领域；
- 具体内容只在这九个领域内填充，并接受五条横向约束检查；
- 未定义的内容显式保留为未知，不用临时故事或模型常识补齐。
