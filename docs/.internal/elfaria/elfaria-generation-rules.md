# Elfaria 个体生成参数与约束

> 版本：elfaria-generation-rules.v19；2026-09-25。
> 第一阶段第二步的人读资料源稿，保存 Elfaria 的参数、适用条件和约束；不作为居民知识。
> 整体流程与算法见 [正式 Genesis 设计](../../zh/developer/designs/elfie/genesis-complete-design.md)，地图事实见[地理资料](elfaria-geography-source-and-map.md)。
> 机器入口为 [program.yaml](../../../config/genesis/program.yaml)。家庭生成参数由 `family.yaml` 发布成员提供；来源摘要更新不表示其他未绑定参数已实现或生效。

## 1. 出生地抽样

出生抽样以地理资料中的 10×10 网格为容器，不使用总人口、家庭规模、中心概率或逐格人口权重。
物种允许区域：Myelle 为 A1/A2/D，Saevi 为 B/D，Tovren 为 C1/C2/C3/D；E/X 禁止出生。
先在所选物种允许的区域间均匀抽取，再在选中区域的合格网格间均匀抽取；区域名单是硬约束。

网格不是村落、住宅或公共地名，不表示等比例尺度；住宅在选中可居住单元内实例化，网格中心不是住宅坐标。

## 1.5 生命周期阶段

三个可领养物种都使用四个左闭右开阶段：幼年期 `[0, childhood_end)` 需要照护，青春期可以逐步独立，成熟期可以结婚、生育并参加活动，老年期需要照护且不再结婚、生育或参加福利活动。物种 generation member 只提供各阶段的本地年龄边界；运行时严格按下界计入、上界进入下一阶段，生命终点不作为存活年龄抽样值。

## 2. 家庭与照护

结婚和生育都只发生在物种的 `mature` 阶段；伴侣年龄差由家庭策略配置，当前为 −2 到 +2 个本地年。
非血缘照护不受生物年龄约束。
幼体各阶段必须有实际照护者；父母不要求当前仍在世，远居、失联与死亡分别表示。
领养及实际赴地年龄严格大于 1 个本地年，当前整数年龄最小为 2 岁；幼年期生活史仍可从出生生成。
亲属展开、生育与生命状态算法见完整设计 6.5.3；新增默认值见第 11 节。

## 3. 学习与职业

从 2 个本地岁起可跟随一名具备相应能力的居民学一项手艺；活动和外出机会只在青春期与成熟期的年龄年中抽样。
普通手艺通常学习 1 年，专业手艺通常 2 年；结业是老师确认能做这门手艺，不代表精通或获得全部相关知识。
职业由实际学习与能力决定，物种不固定职业。

## 4. 赴地准备

赴地前一次简单培训，时长为 3 个本地日；记录本人同意、培训、实际出发与抵达。
不设额外课程模块，也不为了补齐关系生成培训、陪同或交接人员。
地球与新家的信息分别按培训和实际抵达的可知范围取得。

## 5. 知识、候选与生成预算

| 参数 | 取值与条件 |
| --- | --- |
| 知识取得 | 先验资格；无难度的合资格项必得，中等难度为 1/2；每个单元一次稳定抽取 |
| 培训必修 | 完成培训后必得；不替代抵达、设施使用等其他条件 |
| 候选 / 邀请 | 每批目标 5 位 / 每次邀请 1～3 位 |
| 候选尝试 | 每批最多 12 次完整候选尝试；外貌引擎每角色的 96 次内部提案不计入 |
| 人生回溯 | 每个选择点最多 8 个方案，全局最多 64 次；耗尽报无解，不改冻结输入或换种子 |
| 详细经历 | 通常至少 5 段，幼体按真实生活减少，不设固定上限；必要事件先覆盖，不凑数 |

## 6. 地点、住处和通行

公共地点、区域归属、路网与规则由地理资料统一持有；私人住所使用既有树屋、平原住宅、山地居所/洞穴类别，
不新增公共村落或道路。住所须有合法接入口；同区域、出生地标签或通信能力不能替代通行与许可。

湖心岛使用普通渡运；天镜湖山路属于 A1 区域内小路。
地下城保留地点事实，实际进入须另有获准活动与专用路线；云冠城只可观测。
无合法连接的地点不能写成已抵达；公共名称知识不等于内部知识或访问资格。

唯一机器地理来源为 `config/genesis/knowledge/geography.yaml`：
区域矩阵和区域规则派生格属性，地点与路网登记稳定 ID，不另存逐格人口或距离表。

| 项目 | 已审阅值与约束 |

| 区内小路 | 同一子区域内、四方向相邻、无河湖/禁行阻断的可通行陆地格；每连接计一跳 |

## 7. 学习与赴地的实例化要求

一名师傅、一项手艺、一段实际学习与老师确认共同构成学习事实；没有实际学习的个体不强行生成职业。
赴地培训、出发、抵达按先后分别落实，不因模板存在就成立，也不把 0～1 岁时的赴地写成事实。
生成时的老师、时间、路线和结果由第二阶段实例化，不能在共享配置中预存某个个体的经历。

## 8. 人物、关系、命名和事件

私人姓名/真实称呼来自命名规则，身份使用本次生成的稳定 ID；同名不合并。
八位历史人物保持公共身份，不默认成为在世亲属或导师。公共地点与物种名只引用已登记目录。
生活背景提供家庭、邻里、学习和劳动机会；社交要有实际接触，家庭血缘事实与本人是否知情分开。

事件范围包括出生/照护、学习/结业、劳动、迁居、交往认签、家庭接线、伴生照护、成年/结伴、
送别、连线日、静默日、深层探索和赴地。每项仍需校验时间、地点、参与者、前提与结果。

本地一年 196 日；连线日为第 50 日，静默日为第 148 日。深层探索公共窗口每三至五年出现，
不固定为四年；实际进入须有具体窗口、获准路线、推荐/评审、返程与核验。
到门口不等于进入，培训不等于抵达，公共资料不提供运行时房间状态。

## 9. 资料与运行边界

源稿提供审阅输入，发布包提供机器参数；生产是否使用某项规则由消费者与验收证据证明。
当前完整设计的实现差距统一见 [Elfie Conformance 的 ELF-019](../../developer/conformance/elfie.md)，
物种资产与领养资格由物种包及正式契约约束。本文件不承载部署、渲染失败或历史迁移记录。

## 10. 知识条件口径

当前居民目录为 160 个知识单元；C-03-04 为无难度必得项，生成说明不进入居民知识。
条件逐单元生效，公共地理名称与基本关系不能放行地方外观、详细路线或设施内部。

| 知识范围 | 条件 |
| --- | --- |
| 地区生活、生产与传统，共 11 条 | 居住在对应物种地区 |
| 镇内道路比较，共 2 条 | 到过镇中心；不表示进入设施或走遍支路 |
| 深层探索完整流程，1 条 | 行前培训、实际探索、返回与公开核验全部完成 |
| 祖树地方信念，1 条 | 接触当地传统；看到祖树不等于接受信念 |

## 11. 个体生成设计参数

本节对应完整设计的候选年龄及 6.5 个体算法。家庭生成的可调参数集中在
`config/genesis/family.yaml`；这里保留已发布默认值和来源说明，算法、依赖顺序和失败处理只在完整设计维护。

### 11.1 年龄与家庭

| 参数 | 默认值 |
| --- | --- |
| 候选年龄 | 整数，`2 ≤ a ≤ T−4`；T 为物种生命终点，亲属不受此候选上限约束 |
| 家庭生物阶段 | 结婚和生育固定使用每个物种的 `mature` 阶段；阶段边界由物种 generation member 提供 |
| 每对伴侣的子女计划数 | `family.yaml` 中 0/1/2/3 个的概率为 10%/20%/40%/30%；先抽计划，再按当前有效生育年数截断 |
| 出生年份抽样 | `family.yaml` 中结婚后第 `t` 年权重为 `0.75^(t−1)`；已有孩子先占位，剩余年份无放回抽样，同年最多一孩 |
| 有效生育窗口 | 结婚当年不生育；取父亲生育上限、母亲生育上限和当前年份的最小值，折算为结婚后的有效生育年数；双方在世和物种生育年龄仍是硬边界 |
| 伴侣 | 同物种的男性/女性异性模板；先抽一次终身未婚结果（10%），否则在 `mature` 阶段按钟形权重抽结婚年龄；峰值在成熟阶段前四分之一，年龄差 −2/−1/0/+1/+2，权重 1/2/4/2/1，均来自 `family.yaml` |
| 寿命分布 | `F(a)=(a/T)^6`，0≤a<T；到 T 为 1，须条件于已有事实所需的存活年龄 |
| 结伴迁居 | 30%；合法同区域/跨区域住所权重 70/30，不按性别分配 |
| 旁支展开 | 有实际往来的叔伯姑舅姨最多展开 2 个家庭；重点好友最多 2 位 |
| 人物表达 | 关键人物 2～3 个性格特点及 1 项习惯/目标，普通人物简述 |

### 11.2 社交、重要性与履历

| 参数 | 默认值 |
| --- | --- |
| 初始接触机会 | 通常 1～2 位成长伙伴、1～3 位其他邻里；实际学习时通常 1～2 位同门和 1 位师傅 |
| 好友接触强度 | 系数 β=0.8；频率与匹配倍率均为 `0.5+0.5x`；外向倍率为 `0.8+0.4E` |
| 重要性基准 R | 双亲/伴侣/子女 .75、手足 .65、成长伙伴 .35、师傅 .45、邻里/同事 .25 |
| 关系层级衰减 / 好友晋升基准 | λ=.9 / .65 |
| 事件强化 w | 普通接触 .03、持续共同生活阶段 .15、重大支持 .4；日常按年或阶段汇总 |
| 可选活动参与 | `可行性×目的匹配×(0.2+0.8I_before)` |
| 熟人软预算 | `min(30,10+floor(1.5a)+floor(3E+0.5))`；一般约 15～20 人，不填满、不删核心事实 |
| 重要人物履历保留阈值 | I≥.65 |
| 其他履历保留 | `min(.95,I_final×W×(.5+.5G))`；W：婚育/死亡 1，一般近况 .5；G 为目的关联度 |
| 详细故事优先权重 | 事件重要程度 .5、相关人物重要性 .3、目的关联度 .2 |

### 11.3 访问机会

四个宏观区域按森林/平原/山地/混合居住区排列；镇中心是具体地点组。

| 场景 | 基准访问概率 p₀ |
| --- | --- |
| 本地区域中心 / 镇中心（镇外）/ 其他区域中心 | .6 / .8 / .15 |
| 混合居住区的镇中心组 | .6 |
| 祖树，按上述四区域 | .45 / .12 / .10 / .20 |
| 湖边，按上述四区域 | .12 / .45 / .12 / .20 |
| 回澜丘/河湾组，按上述四区域 | .12 / .45 / .12 / .20 |
| 天镜湖山地组，按上述四区域 | .10 / .15 / .45 / .20 |

| 参数 | 默认值 |
| --- | --- |
| 距离衰减尺度 τ | 日常事务 4 日、旅游 12 日，距离使用往返合法通行日数 |
| 对应文化吸引 / 其他 | 1.3 / 1；依物种文化与地点对应关系判定，不由居住区替代 |
| 人格倍率 | 社交 `0.8+0.4E`；新地点 `0.8+0.4O`；风险 `0.8+0.4O−0.2N`；只按主目的取一项 |
| 年龄因子 | 青春期与成熟期的可行动年龄年数 / 当前年龄；幼年期和老年期不进入福利活动抽样 |
| 重复次数幂指数 m | 23；多数正次数接近 1，少量样本形成长尾 |
| 重复次数上限 K | 镇中心组 100；其他开放地点组 64；地下组 1；实际成行仍受路线和时间校验 |
| 可选跨区旅游时长上限 | 可出行生活时段的 10%；迁居、长期学习和赴地单列但仍查时间冲突 |
| 停留 | 赶集 1 日，短游/探亲 1～3 日；求学按实际 1～2 年，长住使用居住区间 |
| 镇内附带公开点 | 由 Program 对每个地点设置附带概率；在镇中心组被选中后抽一次，最多附在其中一趟，不按日重复抽 |
| 湖心岛 | 先选中湖组并经过湖岸，再以 .15 抽取一次；另验渡运与时间，不按每次重复行程重抽 |
| 云冠城 / 地下 | 云冠城进入率 0；地下实际进入仅限合格活动与专用路线 |

对每个地点组只抽一次是否访问：
`p=p₀×距离因子×区域因子×物种因子×年龄因子×人格因子`，各因子均在 `[0,1]` 内。
若访问，再单独抽次数：`N=0（U_visit≥p），否则 N=ceil(K×U_count^m)`；两个抽样使用独立随机域。
次数是本人当前年龄范围内的生命周期次数，不是年次数。过去按年率和日率累计机会的写法已停用。
概率描述的是抽样机会，不保证成行；联合访问、次数、停留与路线的统一算法见正式设计 6.5.6。

### 11.4 角色、目的与文化映射

- 其余直接熟人（同门、旅伴、交换伙伴、非亲属照护者）使用邻里/同事基准 .25；亲属沿父母、手足、子女或好友入口逐层衰减，多角色取最大有效值。
- 普通中心机会在赶集/交换、探亲/交往、观光间初始等权，仅保留有现实前提的项后归一化；全无适用项则不生成机会。求学、诊疗、公共事务由实际需要建立专门槽位，不重复占普通机会，赴地单列。
- 自然景观以观光为主目的；文化吸引映射为 Saevi 家庭文化—祖树、Tovren—回澜丘/河湾、Myelle—天镜湖山地组。匹配乘 1.3，否则 1；文化背景不授予信仰或知识资格。
- 中心类别重叠时按镇上居民、镇外进镇、本地中心、其他中心的顺序选一个基准，不相加。

### 11.5 公共地理基线与基站边界

公共基线知识单元：A-01、A-01-02、B-01、B-02、B-03、B-05、B-05-02、B-05-03、B-06、B-06-16。
期望节点与关系范围见正式设计 6.5.5；取完整原文，依各单元明确公开的命题形成地点与空间关系，不导出完整生成地图。
地球新家实例仅在抵达后按 E-08-02/03 取得。私人地址、受限内部、未登记道路不进入公共基线。

赴地基站目标归属为迷雾镇辖域中的独立设施（宿主 R4C3），镇中心宿主 R5C4；到基站不等于到镇中心。
当前发布包已经按此边界对齐：居民资料、机器地理 `parent_id`、Program manifest 与来源哈希保持一致；赴地接触基站不自动满足镇中心条件，只有明确的镇中心访问条件才会选入对应知识。
后续变更必须同步更新居民知识正文、地理关系、Program manifest 与验收测试，不得把镇中心条件整体放宽给所有赴地者。
