# Elfaria 建筑视觉探索 v0.1

状态：视觉风格已定稿。本文件记录当前选型，后续世界设计以本节“最终定稿”为准。

## 已确定约束

- 文明处于前工业手工业阶段；外星感来自本地材料、生命形态与通信需求，不来自现代工业。
- Aethersense 通信必须塑造建筑轮廓：建筑通过中继树或人工共振冠提高信号距离与稳定度，不能绕过共振认签。
- 普通家庭以中继树为主；商业与共居建筑采用“树＋小型调谐构件”；长老院、学疗院等公共建筑可使用稀有材料构成大型人工共振冠。
- 共振冠应有明确功能结构，例如分叉长肋、空心环列、悬置共振核或导向脉络；避免普通教堂尖塔和装饰性水晶。
- 城镇中应持续出现不同种类的树；山地住宅可以更多依赖矿物屋脊或共振构件，森林和平原住宅更多依赖中继树。
- 避免地球中世纪石城、哥特教堂、通用高等精灵金饰、白壳蓝线生物科幻、现代张拉场馆和霓虹未来城。

## 建筑层级

| 层级 | 通信构成 |
| --- | --- |
| 家庭住宅 | 一户或数户围绕中继树，屋顶只有小型调谐枝、矿物片或接收环 |
| 商业与共居建筑 | 中继树与小型人工共振构件混合，形成连续生活网络 |
| 长老院、学疗院 | 大型人工共振冠承担主要放大，周围树群承担辅助与备份 |

## 本轮盲测

- 不使用已有长老院、学疗院参考图作为生成输入。
- 长老院生成两种独立共振冠方案；学疗院生成两种独立共振冠方案。
- 完成后再与已有参考图比较：第一眼辨识度、通信逻辑、前工业可信度、城镇扩展性。

## 当前收敛结论

- 长老院以既有尖顶参考的尺度、比例和可建造感为母版，吸收“三肋悬核”方案的通信轮廓；参考约占七成，候选 A 约占三成。
- 候选 A 删除中央大型悬挂物，共振冠降低约三至四成；三根分叉肋不闭合，顶部只保留小型固定共振核。上部不出现人物或装饰性雕像。
- 三根主肋采用多束架构木长期培育、层压和纤维缠束，外覆轻质树脂—矿粉壳；石材只作基础。高处装配可利用飞行能力，但不依赖大型工业机械。
- 长老院镜头从南偏西望向东北，背景为较高山体；周围保留中继树，但公共通信主要由人工共振冠承担。
- 空心环列长老院与两张学疗院盲测方案停止深化，仅保留为探索记录。
- 学疗院后续采用“前部一排低矮教学/诊疗建筑＋后部较高主楼”的大容量布局，再统一使用长老院确定后的材料和共振构件。

## 最终定稿

- 长老院采用 [伴生架构木方案](elfaria-image-review/town/elfaria-mistyville-place-elder-council-hall-final.png)：低矮三翼、空心共振冠、伴生树与架构木共同构成公共通信节点。
- 学疗院采用 [前低后高院落群方案](elfaria-image-review/town/elfaria-mistyville-place-learning-healing-hall-final.png)：它不是单一图书馆，而是教学、诊疗、档案、恢复和住宿混合的公共建筑群。
- 学疗院前部低馆承担启蒙教学、接诊、药材处理、家庭问询和短期恢复；后部主馆承担档案、大课堂、复杂诊疗与管理；更后方及两侧延伸为学员、医者、患者家属和轮住人员的住宿区，当前画面未完整展示。
- 画面里的架柜不只存放书籍，也存放病案、药材、标本、教学器具和治疗工具。
