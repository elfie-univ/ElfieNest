# 用户指南

ElfieNest 是一个让 Elfie 住在你电脑里的桌面应用。这份指南写给普通电脑用户：
它说明应该点哪里、每个区域能做什么，以及遇到问题该怎么办。你不需要先学习开发技术，
照着页面提示操作即可。

## 一句话使用路径

```text
安装配置 → 首次配置 → 核心配置 → 领养一只 Elfie → 开始聊天
```

如果你加入的是别人已经准备好的 Nest，直接登录后阅读[日常使用](./run)即可。如果你是所有者或管理员，
请先完成[核心配置](./ready)，再邀请成员。

管理员的路径是：

```text
打开管理台 → 选择模型来源 → 配置 Elfie 粮食 → 检查状态监控 → 邀请大家使用
```

## 从这里开始

1. 先按[安装配置](./install)安装适合你电脑的桌面应用。
2. 按[首次配置](./configuration)完成向导并创建第一位管理员。
3. 如果你负责管理 Nest，先完成[核心配置](./ready)，连接模型来源、准备粮食并检查状态。
4. 按[领养第一只 Elfie](./adoption)完成应用里的双向邀请流程。
5. 阅读[日常使用](./run)：聊天、查看精灵档案，以及在同一网络下用手机访问。
6. 如果你是管理员，再阅读[管理台与房间监控](./manage)。
7. 如果出现异常，直接打开[故障排查](./troubleshooting)。

## 主界面分别做什么

| 区域 | 在这里做什么 | 谁能看到 |
| --- | --- | --- |
| 聊天 | 和 Elfie 对话、查看聊天记录 | 所有人 |
| 精灵 | 查找 Elfie、打开档案、开始聊天 | 所有人 |
| 管理台 | 管理用户、床位、模型连接、粮食和系统设置 | 管理员 |
| 状态监控 | 查看服务健康、可用模型和最近事件 | 管理员 |
| 3D 监控 | 查看 Nest 里的活动、切换 3D 观察位置 | 管理员 |
| 我的 | 修改个人资料、密码、语言和外观 | 所有人 |

聊天和精灵页面也可以在手机上打开：在应用里扫描二维码即可。手机是可选的伴随访问
方式，不需要再安装一套 ElfieNest。

## 关于当前版本

ElfieNest 目前还是预览版本。可用的安装包会出现在[官方 Releases 页面](https://github.com/elfie-univ/ElfieNest/releases)。
如果页面暂时没有安装包，不要为了使用应用而直接安装源码；请等待官方包，或向提供你访问权限
的人索取正确的安装包。

[开发者文档](/zh/developer/)面向构建、测试或诊断项目本身的人，和这份普通用户指南分开维护。
