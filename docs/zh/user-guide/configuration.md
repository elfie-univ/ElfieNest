# 首次配置

第一次打开 ElfieNest 时，会出现四步设置向导。你在步骤之间移动时，页面只会先保存草稿；
直到最后确认，应用才会真正开始安装或创建内容。

## 第 1 步：创建第一位管理员

填写：

- 登录账号；
- 在应用里显示的名称；
- 密码和确认密码。

这个账号就是 Nest 的所有者。请把密码保存在安全的地方。之后，所有者可以在管理台创建
普通成员和其他管理员。

## 第 2 步：选择本地离线保障

“使用本地 Ollama”是可选项：

- 如果希望这台电脑可以使用本地模型，就打开它。ElfieNest 会检查本地服务，并可能在安装
  时下载你选择的模型，并准备一份最后备用的**保底粮**。
- 如果准备之后由管理员配置模型订阅，就保持关闭。

你不需要为了完成设置而理解模型名称。如果你不是 Nest 管理员，请先问负责管理的人应该
选择哪一项。

## 第 3 步：设置床位数

选择 Nest 需要多少个床位。当前向导接受 4–32 个床位。这表示房间容量，不会自动创建同样
数量的 Elfie。

## 第 4 步：检查并安装

确认汇总内容后，点击“确认配置并开始安装”。页面会显示总进度和当前阶段。安装进行时请
等待页面完成；这是设计上的行为，安装页不会提供取消或返回。

如果某个阶段失败，点击“从失败阶段重试”。应用会重新检查已经完成的阶段，不需要你重新
填写所有设置。

## 设置完成以后

安装完成后点击“安装完成并进入管理台”。安装完成代表 Nest 建起来了，但不一定已经可以日常聊天：

- 打开本地保障时，向导会准备一份最后备用的保底粮；管理员仍要准备并启用日常使用的常用粮；
- 关闭本地保障时，向导不会准备模型连接或粮食，管理员必须继续完成[核心配置](./ready)。

请在邀请成员领养或聊天前完成这次检查。普通成员使用管理员创建的账号登录，不需要重新走所有者设置。

## 之后如何配置模型和粮食

管理员可以进入“管理台 → 模型订阅”，添加远程模型连接、授权受支持的 ChatGPT 订阅，或管理本地
Ollama；然后进入“管理台 → 粮食策略”，为 Elfie 配置日常使用的常用粮和最后备用的保底粮。完整步骤请看
[核心配置](./ready)。应用会把连接保存在本机的受保护存储中。不要把 API 密钥、密码或一次性授权码
写进公开文档，也不要发给其他用户。

## 日照与休息时间

进入“管理台 → 系统配置 → 高级设置 → 精灵巢环境”，配置日出、日落、休息三个时间点。
默认分别为 06:00、18:00、00:00，由它们划分白天、晚上和深夜。手动时间点必须依次为
日出、日落、休息，再到次日日出。

选择“手动配置”填写日出和日落；或选择“跟随本地”，点击“使用电脑位置”。浏览器只在
点击后请求定位权限。ElfieNest 在受保护的本机设置中保存大致位置，按日期在本地计算
日出和日落，不请求外部日照服务。休息时间始终手动设置。点击“保存环境设置”后，运行中
的精灵巢会在下一次 Tick 使用新设置，无需重启。

自动日照使用已保存的位置，以及精灵巢所在电脑的本地日期和时区。搬到其他地点后，再次
点击位置按钮即可更新位置；打开的设置页会自动刷新当天结果。极昼、极夜没有日出或日落
时会明确提示，环境分别保持白天、深夜状态。Lab 的“实时”使用相同的正式 Nest 规则和
隔离的开发配置，三个手动光照预览不会覆盖已保存的日程。
