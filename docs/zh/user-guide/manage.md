管理台面向 Nest 所有者和管理员。普通成员不会看到这些入口，可以直接使用聊天和精灵页面，不需要理解管理功能。

## 管理员先做什么

完成[首次配置](./configuration)后，按[核心配置](./ready)操作：选择本地或远程模型来源，验证至少一个模型，准备好粮食，
再检查“**状态监控**”。以后聊天没有回复，也应先从这个页面开始查。

## 每个栏目负责什么

从桌面左侧导航打开“**管理台**”。左侧栏目按下面的用途分组：

| 栏目 | 管理员可以做什么 |
| --- | --- |
| **状态监控** | 刷新系统健康状态，查看用户和精灵数量，检查模型服务及可用模型，阅读最近事件。 |
| **用户管理** | 创建普通成员或管理员，设置每位成员的领养上限，重置密码；名下仍有精灵的成员不能直接移除。 |
| **精灵管理** | 按用户、物种、粮食或状态筛选；查看档案、床位和当前主粮；需要时修改 Elfie 的主粮。 |
| **精灵巢管理** | 把房间容量设为 4–32 个床位，分配或清除床位，查看平面布局并打开房间预览。 |
| **模型订阅** | 添加远程连接或受支持的 ChatGPT 账号，安装/启动本地 Ollama，下载模型，重新读取模型列表并验证连接。 |
| **粮食策略** | 查看、创建、编辑、启用、停用或归档粮食；选择它使用的模型能力；设置所有人或指定用户可见。 |
| **系统设置** | 查看精灵容量和成员额度，启用系统能力，调整登录保护或低频运行设置。 |

每次只修改一个区域，并等页面出现成功提示后再继续。不要把 API 密钥、密码或一次性授权码粘贴到聊天里，也不要发给普通成员。

当前本地账号总数上限是 16 个，其中管理员最多 5 个。

## 粮食就是给普通用户看的说法

ElfieNest 故意使用**粮食**这个名字，不要求普通用户学习模型的技术细节。这个友好说法背后，管理员是在准备 Elfie 能使用的能力：

- **常用粮**是日常选择，必须有能工作的**主要模型**并且处于启用状态。
- **保底粮**是系统最后的备用。普通用户不能直接选择它；如果希望日常粮食不可用时还有后手，就要把它配置好。
- **自定义粮食**适合需要不同速度、质量或能力组合的场景，可以对所有人可见，也可以只给指定用户。

推理、视觉、工具和备用能力是主要模型之外的可选角色。服务商不可用、模型被停用，或粮食处于未配置、停用、已归档状态时，
这份粮食可能会降级或不可用；先修复或验证模型连接，再依赖它。Elfie 档案里的“**主粮**”由所有者从管理员允许且可用的粮食中选择；
普通成员不需要编辑背后的模型组合。

## 容量、用户额度和床位不是一回事

管理台里会看到两个不同的限制：

- **精灵巢床位容量**：房间有多少个位置，在“**精灵巢管理**”里调整并分配床位。
- **成员领养上限**：一位成员最多可以领养多少只 Elfie，在“**用户管理**”或“**系统设置**”里调整默认值或个人值。

增加其中一个，不会自动增加另一个。一次新的领养既需要成员额度，也需要 Nest 还有空闲位置。

## 用普通话理解“系统设置”

“**系统设置**”主要有三类控制：

- **精灵额度**：显示 Nest 当前容量、已经领养的数量和剩余空间，并设置每位成员的默认领养上限。
- **系统能力**：控制“网络搜索”和“本地文件（只读）”等可选能力。每项能力都有自己的设置和“**验证**”按钮，只开启 Nest 真正需要的能力。
- **高级设置**：保护登录，并调整低频运行参数。大多数人不需要改这里；运行参数修改后必须重启 ElfieNest 才会生效。

## 状态监控和 3D 监控不是一回事

“**状态监控**”是管理台里的仪表盘，回答“Nest 健康吗？”它显示服务明细和最近事件。

“**监控**”是单独的 3D 观察页面，回答“房间里正在发生什么？”：

- “**总览**”在可用时显示整个房间；
- 位置按钮切换观察位置；
- “**复位**”回到默认视角；
- “**暂停观察**”只暂停画面，不会停止 Nest，也不会暂停 Elfie 的生活；
- “**沉浸观察**”隐藏周围导航；
- “**重试 3D**”在场景没有加载时重新尝试。

3D 房间可能需要一点时间加载。加载期间仍可使用聊天、精灵档案和管理台。管理员可以扫描监控二维码在手机上查看；手机和电脑必须在同一局域网，
手机仍然需要管理员账号。
