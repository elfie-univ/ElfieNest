# 常见问题

## ElfieNest 是什么？

ElfieNest 是 Elfie 生活、记住经历并和你相处的本地家园与桌面应用。你可以在里面聊天、查看档案，以及观察房间。

## Elfie 和 Nest 分别是什么？

**Elfie** 是具体的一位陪伴者；**Nest** 是 Elfie 生活的共享家园和房间。你负责领养 Elfie，管理员负责配置 Nest。

## “粮食”是什么意思？

**粮食**是 ElfieNest 为普通用户准备的友好说法，表示 Elfie 用来思考和聊天的能力，背后的技术细节不需要你理解。
**常用粮**是日常选择，**保底粮**是最后备用。管理员从可用模型中准备并启用粮食；普通用户只需在档案提供多个选项时，选择一份健康且自己可见的主粮。

## 需要先懂代码或 AI 模型吗？

不需要。安装桌面应用、完成首次配置，然后使用界面里的页面即可。模型连接和粮食属于管理员工作；开发者可以去阅读单独的[开发者文档](../developer/)。

## 必须使用本地模型吗？

不必须。管理员可以选择两种来源：

| 来源 | 对你的实际影响 |
| --- | --- |
| 本地 Ollama | 模型留在运行 Nest 的电脑上，对网络依赖较少，但会占用磁盘和内存，而且本地服务必须运行。 |
| 远程订阅 | Nest 使用网络服务商的模型，需要联网，并可能受服务商规则、账户额度或费用影响；对话内容会发送给该服务商。 |

两种方式可以同时保留。管理员的完整清单请看[核心配置](./ready)。

## 为什么不能聊天？

聊天需要正在运行的模型服务，以及至少一份已启用、健康并带有主要模型的粮食。请让管理员依次检查“**管理台 → 状态监控**”“**模型订阅**”和“**粮食策略**”。
如果档案提示“当前没有可用主粮”，管理员必须先准备一份。

## 谁来配置粮食？

Nest 所有者或管理员。他们决定使用哪种模型来源、验证模型、准备常用粮和保底粮，并控制自定义粮食对哪些用户可见。
Elfie 的所有者可以从自己有权限使用的健康粮食中选择当前主粮。

## 可以在手机上使用吗？

可以，通过桌面应用里的二维码访问。手机和电脑需要在同一个局域网，手机仍然沿用账号权限。不需要另外下载手机 App。

## 为什么看不到管理台或监控？

这两个区域只给 Nest 所有者和管理员使用。普通成员仍然可以聊天、查看 Elfie 档案和修改个人设置。

## 关闭窗口会停止 ElfieNest 吗？

不会。关闭窗口会把应用隐藏到托盘，让本地服务继续运行。想彻底停止时，请选择“**退出 ElfieNest**”。

## 我的数据放在哪里？服务商能看到吗？

Nest、精灵档案和设置会保存在运行应用的那台电脑上。使用本地模型时，对话通常留在这台电脑上，但管理员开启的在线工具可能会访问外部服务。
使用远程模型时，服务商会收到回答所需的对话内容，也可能按其规则收费。请保护好运行 Nest 的电脑，遵守服务商政策，不要把整个数据目录发给客服。

## 这里没有回答我的问题怎么办？

先看[故障排查](./troubleshooting)。仍然需要帮助时，请提供页面上看到的错误文字、应用版本和复现步骤，但不要提供密码、密钥或一次性授权码。
