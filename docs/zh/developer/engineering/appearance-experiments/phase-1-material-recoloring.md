# 外观实验——第一阶段：材质换色

**状态：** 狐狸和狗均已完成技术可行性验证；尚未接入生产实现。

**日期：** 2026-08-17

## 本阶段范围

本阶段只验证红框中的四项：

- 毛色替换；
- 白色/浅色区域独立保留；
- 保留毛根、毛尖、阴影和高光；
- 保留毛束、毛流和细毛纹理。

形状、GLB、BlendShape、大块花纹、花纹颜色排列、局部标记和标记安全区明确不在本阶段。

## 实验方法

实验直接使用 Godot 中原始的狐狸和狗场景及其烘焙好的毛发源贴图，没有重生成模型，
也没有调用图片生成服务。

临时着色器对比了四种情况：

1. 原始材质；
2. 全局换色，作为负面对照；
3. 换色并保护浅色/深色区域；
4. 最终候选方案：保护浅色/深色区域，并使用有界明暗映射和轻微毛发细节保留。

验证通过的方向是：

- 采样真实的原始毛发贴图，而不是叠一层半透明遮罩或灰色蒙版；
- 把目标颜色当作毛发中间色，在有界范围内迁移明暗；
- 用原始贴图的明度和中性色特征保护浅色区域，因为狗的浅色毛并不是纯白；
- 保留爪子、耳缘等深色区域；
- 不再叠加一层宽泛的灯光，避免之前的灰蒙蒙效果。

### 十色库复核

把十种颜色直接套到原始 GLB 场景并用同一套毛发着色器渲染。第一轮暴露了两个产品问题：
过深的颜色会压低眼睛和鼻子的辨识度，相近的棕色放在同一批五个候选里差异不够明显。
第二轮把最深色调整为烟炭/烟黑，并保留原始毛发的明暗和细节迁移。

## 审查结果

| 检查项 | 狐狸 | 狗 | 结果 |
| --- | --- | --- | --- |
| 物种识别和轮廓保持不变 | 通过 | 通过 | 不需要改 GLB 或形状 |
| 毛色产生明显差异 | 通过 | 通过 | 银灰、奶油、深棕可区分 |
| 浅色区域保持独立 | 通过 | 通过 | 需要按物种配置源贴图保护参数 |
| 毛流和毛发纹理保留 | 通过 | 通过 | 最终候选没有塑料感或大面积灰雾 |
| 只做全局换色是否可接受 | 不通过 | 不通过 | 会破坏独立的浅色/深色区域 |

本次产品视角评分是受控截图下的人工估计，不是自动化质量指标：狐狸约 **8.8/10**，
狗约 **8.4/10**。与 AI 参考图的剩余差距，主要来自 GLB 原有的毛发密度和烘焙细节上限；
本实验没有改变几何，也没有删除原始毛发纹理。

## 阶段结论

第一阶段作为两个物种的技术可行性基线，通过。生产实现应采用可复用的“源贴图换色”路径，
并为每个物种配置浅色区域保护参数；不应继续使用之前那种大范围遮罩/局部颜色覆盖方案。

本记录只记录实验结果。本次验证没有修改生产着色器、GLB 或运行时行为。
