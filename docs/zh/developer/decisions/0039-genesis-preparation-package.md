# ADR-0039：注册 Genesis 准备资料包，不激活运行

- **状态：** accepted
- **日期：** 2026-09-22
- **范围：** 配置归置与准备资料包完整性

> 下文“只能为草稿”的发布限制由 [ADR-0040](./0040-genesis-source-publication-before-activation) 取代；封闭清单和禁止双读的决定继续有效。

## 决定

经审阅的准备资料放在 `config/genesis/`，不再依赖被忽略的 build 目录。
注册 `program.yaml`，其余文件逐一进入绑定摘要的显式清单。检查器验证技术完整性，
不决定生命语义；在独立完成发布与强类型消费者实现前，拒绝 published 状态。

现有 world/species 生产读取器不变，不引入双读、回退、新创建器或运行期源资料依赖。
以后切换时须退役旧创建输入，同时保留必要的运行时外貌资产。
缺少地理、课程证据或未定政策时阻止发布，不由加载器填造默认值。

## 结果

资料包位置稳定、可发现。配置清单继续封闭：显式枚举成员，不以整目录白名单放行。
草稿完整性与生产就绪是不同的校验。配置契约 1.5 记录准备边界；生命语义仍归 Elfie Genesis。
