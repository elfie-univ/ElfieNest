# ADR-0034：治理切换期间兼容旧契约版本标记

**状态：** 已接受
**日期：** 2026-09-02
**范围：** 治理契约版本提取与不可变基础变更检查

## 背景

治理检查器已经要求契约修改同时更新中英文镜像并升级版本。但 `main` 上的旧契约仍使用
历史格式 `Status: normative, version N`（以及对应的中文格式），新契约则使用规范的加粗
`Contract version` 标记。不可变基础检查器会使用旧版 main 实现读取候选版本；当合法候选
修改这些旧格式契约时，检查器无法读取基础版本，于是在比较版本前就拒绝了变更。

## 决策

`scripts/governance/change_policy.py` 同时接受规范的双语版本标记和历史的双语版本标记。
这只增加解析兼容性；检查器仍然要求中英文契约成对修改、版本升级以及匹配的 ADR。新建或
新修订契约继续使用规范的加粗标记。

架构治理测试覆盖两种标记格式。不引入产品模块、契约 authority 或第二份契约内容事实源。

## 后果

即使 `main` 仍含有旧格式标记，不可变基础门也能正确评判契约迁移。剩余旧标记可以逐步
规范化，不需要放宽治理规则或增加临时检查器绕过。
