# ADR-0007：Brain 回合、心智状态与跨回合活动所有权

**状态：** 已采纳
**日期：** 2026-08-12

## 背景

ADR-0006 和 Elfie 2.0 契约已经确定 Brain 拥有十个概念系统、三类输入源和三类决定
输出，但这一聚合层决策尚未固定 Turn、权威心智状态、有界多步思考、长思考中断、跨
回合活动与恢复的内部语义。缺少下位规约时，执行计划可能误把 Payload 标签当成 Turn
隔离，把通信或身体控制暴露为认知 Tool，让模型直接写入持久状态，或者在持久工作尚未
具备边界和恢复能力前开放 Motivation。

## 决策

采用 Brain 内部架构契约 1.0，作为 `elfie/brain/` 内部的规范性目标。

- Brain 有十个概念所有者：事件工作区、自我定位、自我认知、情绪、能量、动机、记忆、
  思考中枢、跨回合活动和心智整理。必需治理与持久化机制不是平级心智系统。
- 事件工作区每次只把一个来源域接纳为一个不可变 Turn。Communication、Embodied 和
  Internal 事件可以共享已提交心智状态，但不能共享 Frame、临时推理状态或输出 authority。
  每个 Turn 还绑定一个 Interaction Scope，独立会话、身体 generation 和内部原因不能只因
  来源域相同就被混在一起。
- 思考中枢拥有上下文组装和有界 Model/Skill/Tool 循环。Tool 是确定性沙箱内的认知
  工作；Communication、Body 和设备访问仍是外设，不属于 Tool。
- 每个 Turn 只产生一个决定。确定性串行边界只允许至多一个外部域，并可伴随一个已校验
  跨回合活动请求；心智状态候选只能由真正的权威所有者提交。
- 跨回合活动采用无副作用 Preflight 和 Turn 后 Commit。到期工作以 Internal 事件重新
  进入认知。动机和心智整理不能创建活动或直接对外执行。
- 长短 Run 只有在临时状态隔离时才可重叠；陈旧、过期或基于旧身体 generation 的结果
  不能通过唯一提交边界。
- 持久 Journal、State、Checkpoint、预算、幂等、因果 Trace 和回执对账属于认知基础
  设施，不是另一个心智。

十个概念在规模较小时可以采用扁平文件。只有真实状态、契约或行为需要时才建立对应包。
本决策不固定存储 Schema、Prompt、评分公式、模型供应商、阈值或进程拓扑。

## 后果

Brain 1.0 契约从属于 Elfie 2.0 契约：Elfie 继续负责聚合和两条外部线路，Brain 契约
负责内部认知生命周期。根系统模块、Infrastructure 依赖方向、Nest authority、身体
authority 和公开 Facade 均不改变。

当前产品代码在另行批准的垂直切片关闭 Brain 台账前会保持有意不合规。第一份实现计划
必须从这些差距生成，不能建立十个空目录，也不能在跨回合活动具备边界和恢复能力前启用
自主 Motivation。

被拒绝的方案包括：把全部设计继续塞进 Elfie 聚合契约、把每个机制都列成平级模块、给
混合感知 Frame 增加来源标签就声称完成隔离、把外设暴露为 Tool、用模型文本证明执行，
以及在开放自主行为后才补状态和恢复边界。
