# ADR-0040：Genesis 源资料先发布，创建链后激活

- **状态：** accepted
- **日期：** 2026-09-24
- **范围：** Genesis 资料包发布与运行时激活边界

## 决定

经作者审阅且摘要绑定的 `config/genesis/` 可先发布为版本化源资料包，之后再接入产品。
发布要求成员清单封闭，入口、成员与来源摘要一致，造物者源稿章节绑定到目标项，居民
知识逐单元精确投影，并且没有未解决的知识条件。发布冻结资料版本；内容变化须另发
新版本。

资料发布不等于创建链激活。Adoption 在强类型 Genesis 消费者、语义与可行性校验、
单一路径切换验收之前，继续使用现有 world/species 路径。已发布清单另列激活阻塞。
Myelle 留在包中，因缺少 Godot 角色资产而在物种目录保持 `draft`，不可供领养。
Saevi/Tovren 外貌由作者决定免于重新渲染、按人工接受处理；技术渲染记录不改写。

## 结果

本决定取代 ADR-0039 中“准备包只能为草稿”的发布限制；封闭清单、摘要校验和禁止
双读的规则继续有效。YAML 标为 published 或通过包完整性检查都不能证明生产 Genesis
行为；生产切换仍须单独实现和验收。
