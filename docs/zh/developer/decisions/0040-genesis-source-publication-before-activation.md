# ADR-0040：Genesis 源资料先发布，创建链后激活

- **状态：** accepted
- **日期：** 2026-09-24
- **范围：** Genesis 资料包发布与运行时激活边界

## 决定

经作者审阅且摘要绑定的 `config/genesis/` 可先发布为版本化源资料包，之后再接入产品。
发布要求成员清单封闭，入口、成员与来源摘要一致，造物者源稿章节绑定到目标项，居民
知识逐单元精确投影，并且没有未解决的知识条件。发布冻结资料版本；内容变化须另发
新版本。

资料发布和可用性仍是两个决定。资料包只有在强类型 Genesis 消费者、语义与可行性校验、
单一路径切换验收完成后才可激活。当前资料包的单路径切换已经完成：Adoption 和 Genesis
通过登记的 Adapter 读取已发布的 `config/genesis/`，不再读取退役的 world/species 生产路径。
清单仍按物种记录激活阻塞。Myelle 因缺少 Godot 角色资产而在物种目录保持 `draft`，不可
供领养；Saevi/Tovren 外貌由作者决定免于重新渲染，技术渲染记录不改写。

因此 App 的可用性投影只选择已激活资料包中、创建规则、人生可行性和运行资产均通过校验的
物种；不能仅凭源资料发布就开放候选。激活是经验证后接入现有
Adoption → ResidentAdmission → Elfie Genesis 单链的独立交接，不新增第二条创建路径或
管理员白名单。

## 结果

本决定取代 ADR-0039 中“准备包只能为草稿”的发布限制；封闭清单、摘要校验和禁止
双读的规则继续有效。YAML 标为 published 或通过包完整性检查，都不能证明所有 Genesis
语义门已经完成；剩余行为和入驻缺口统一由 ELF-019 跟踪。未来新增资料包或物种仍需独立
激活证据；当前资料包已激活不代表 draft 物种可用。
