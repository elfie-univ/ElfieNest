# ADR-0024：缺少外部环境时使用显式本地 checkpoint

## 状态

已接受。

## 日期

2026-08-16。

## 范围

任务收敛与本地提交前 checkpoint。

## 背景

收敛台账正确地把缺少 Windows/Linux 主机记录为 `blocked`，但严格完成检查也会阻止
当前主机上所有可执行检查通过后的本地 checkpoint 提交。这样把无法取得的外部证据
和代码失败混成了同一种条件。

## 决策

- 只有当缺失证据是因为没有可用操作系统或已安装主机时，阻塞行才能声明机器可读的
  `blocker_class: "external_environment"`。
- 所有 `task-closure*.json` 文件都属于治理产物，因此按任务拆分的台账不会被误判为产品/实现
  变更。
- 本地提交前门禁可以显式接收 `--allow-external-environment-blockers`。它只允许这些
  已分类的阻塞行通过 checkpoint，不改变行状态，也不清除 residual。
- 默认门禁、CI、受保护分支检查和最终完成仍然严格执行。代码失败、证据缺失和未分类
  阻塞不能使用这个例外。
- 治理变更与实现变更分开审查的规则不变。

## 结果

本地工作可以在不伪装跨平台验收完成的前提下保存。缺失主机和下一次可重放检查仍保留
在台账中，之后必须由匹配主机或 CI 完成最终收口。
