# ADR-0024：缺少外部环境时使用显式本地 checkpoint

## 状态

已废止。

> 该决策已于 2026-08-17 废止。外部环境缺口继续作为一致性台账中的开放 residual，不再
> 保留按任务的本地例外参数。本 ADR 仅保留为决策历史。

## 日期

2026-08-16。

## 范围

历史上的不可用平台验收本地 checkpoint。

## 历史记录

过去曾用本地例外把缺少主机的外部证据与代码失败区分开。该机制已随按任务收敛机制一起
移除。外部主机缺口仍记录为开放的一致性台账 residual，并必须由 CI 或匹配主机在受保护
交付前补齐；不存在把它转换为成功的本地参数。
