# ADR-0025：保持可执行架构测试通过格式检查

- **状态：** 已接受
- **日期：** 2026-08-17
- **范围：** 仓库质量与架构测试维护

## 背景

当前主线的一个可执行架构测试存在既有 Ruff 格式诊断。由于该测试属于治理面，文件未
格式化时，正常的质量基线就无法收口。这次修复是机械格式调整，不改变断言、验证规则
或架构 Baseline。

## 决策

可执行架构测试继续遵循仓库锁定的 Ruff 格式化规则。只要不改变测试行为、规则输入和
Baseline 条目，纯格式修复可以作为治理专用变更交付。任何架构规则的语义变更仍必须
单独建立双语 ADR，并与产品实现保持分离。

## 后果

仓库可以在不削弱治理覆盖、不新增豁免的前提下，将质量基线保持为零新增格式诊断。纯
格式治理提交可以与 Provider 或产品变更独立审查。

被拒绝的替代方案包括：把架构测试排除在格式检查之外、把这些诊断永久登记为债务，或
把治理修复和产品实现混在一起。
