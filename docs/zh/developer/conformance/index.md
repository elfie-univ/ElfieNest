# 一致性台账

一致性台账是临时迁移清单，记录相对于契约的精确已知缺口及其删除证据。台账不能
重定义目标，也不能批准新增债务。两个子契约台账现在都已准备收口；实现收口提交后，
再以独立治理变更删除。

已退役的通用 System、App、Model/Food/Tool 与 Brain 台账分别达到自身零债务门槛，因此
对应临时文件和空基线已删除；剩余两个子契约台账已经没有开放条目：

- [Elfie 内部架构一致性](./elfie)——Profile/Brain 所有权与 Genesis 迁移已准备收口。
- [Nest–Godot 语义世界一致性](./nest-godot-semantic-world)——逐条款、逐目录复查已准备收口。
