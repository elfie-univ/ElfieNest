# 一致性台账

一致性台账是临时迁移清单，记录相对于契约的精确已知缺口及其删除证据。台账不能
重定义目标，也不能批准新增债务。当机器基线清零且全部缺口关闭后，删除对应台账。

已退役的通用 System、App、Model/Food/Tool 与 Brain 台账分别达到自身零债务门槛，因此
对应临时文件和空基线已删除；这不代表后来发现的子契约缺口也已经关闭。当前仍有两份
活动台账：

- [Elfie 内部架构一致性](./elfie)
- [Nest–Godot 语义世界一致性](./nest-godot-semantic-world)——按契约条款和全部目录复查后，
  原来的“零债务”结论不成立，因此重新打开。
