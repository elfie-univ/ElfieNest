# 一致性台账

一致性台账是临时迁移清单，记录相对于契约的精确已知缺口及其删除证据。台账不能
重定义目标，也不能批准新增债务。

已退役的通用 System、App、Model/Food/Tool 与 Brain 迁移台账分别达到自身零债务门槛，
因此对应临时文件和空基线已删除。新的聚焦迁移建立独立台账，不重新恢复通用 Brain 台账：

- [配置管理一致性](./configuration-management)——删除 Elfaria/Profile Canon 的硬编码重复来源，
  并证明已提交精灵脱离创建资料包也能恢复，当前仍为开放状态。
- [Provider/模型可用性一致性](./provider-model-availability)——Endpoint 级能力、在用核心
  证据与统一健康投影仍为开放状态。
- [Elfie 内部架构一致性](./elfie)——严格 Profile 所有权、一次性 Genesis 归位、创建输入销毁与
  最终所有者隔离仍为开放迁移。
- [Nest–Godot 语义世界一致性](./nest-godot-semantic-world)——逐条款、逐目录复查已准备收口。
- [服务生命周期一致性](./service-lifecycle)——已接受契约与当前启动、所有权和入口之间的
  开放缺口。
- [Elfie Memory 一致性](./elfie-memory)——记录 Memory 设计的实现状态与剩余外部验收门禁。
- [Elfie 情绪一致性](./elfie-emotion)——记录已接受 Emotion 设计仍待下一轮处理的语义
  召回率和慢层纠正 Scope 覆盖债务。
- [Elfie Selfhood 一致性](./elfie-selfhood)——当前 Selfhood 载荷仍拥有动态 Profile/Canon 投影；
  运行时身份必须改为创建时生成且不依赖资料包的 Selfhood 结果，因此仍为开放迁移。
