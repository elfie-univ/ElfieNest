# 一致性台账

一致性台账是临时迁移清单，记录相对于契约的精确已知缺口及其删除证据。台账不能
重定义目标，也不能批准新增债务。当机器基线清零且全部缺口关闭后，删除对应台账。

已登记的 System、App、Model/Food/Tool 与 Brain 债务已经清零，因此对应临时台账和
空基线已删除。Brain 契约现在由永久架构测试直接守护。当前 Elfie 2.0 生命系统与
Nest–Godot 语义世界仍有主体级开放缺口：

- [Elfie 内部架构一致性](./elfie)
- [Nest–Godot 语义世界一致性](./nest-godot-semantic-world)
  - [已批准迁移规约](./nest-godot-semantic-world-migration)
