# 一致性台账

一致性台账是临时迁移清单，记录相对于契约的精确已知缺口及其删除证据。台账不能
重定义目标，也不能批准新增债务。原有两个子契约台账已经准备收口；配置管理另有一份
开放台账，用于已批准的结构迁移。

已退役的通用 System、App、Model/Food/Tool 与 Brain 迁移台账分别达到自身零债务门槛，
因此对应临时文件和空基线已删除。Provider/模型可用性针对行为契约 1.8 新增了一份窄范围
台账。当前已注册工作如下：

- [配置管理一致性](./configuration-management)——源码默认值集中、强类型加载与单副本
  打包仍为开放状态。
- [Provider/模型可用性一致性](./provider-model-availability)——Endpoint 级能力、在用核心
  证据与统一健康投影仍为开放状态。
- [Elfie 内部架构一致性](./elfie)——Profile/Brain 所有权与 Genesis 迁移已准备收口。
- [Nest–Godot 语义世界一致性](./nest-godot-semantic-world)——逐条款、逐目录复查已准备收口。
