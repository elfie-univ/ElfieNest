# 虚拟外貌生成最终设计

**状态：** 当前发布基线已确认。正式使用的13个语义区域保持冻结。跨身体外星纹样实验已记录，
但正式候选暂缓并禁用该功能；它不是本次发布的前置条件。

> 设计关系：**所属模块：**Elfie / Embodiment；**上级设计：**[Elfie 顶级模块设计](../elfie-top-level-module-design.md)；
> **下级设计：**无；**规范性契约：**[物种资源包契约](../../../contracts/species-asset-package.md)；**当前架构：**[模块边界](../../../architecture/module-boundaries.md)；
> **一致性台账：**无；**领域资料来源：**Elfaria 物种与外貌输入（使用稳定资料标识）。

## 范围与所有权

本文定义 Elfie 的 Godot 虚拟躯体在创建时生成并保持不变的外貌。结果属于
`Profile / VirtualAppearance`；Godot 拥有几何、蒙皮、材质和渲染事实。本文不描述实体玩具外形。

当前发布外貌由几何外形和三层生效的皮肤组成；跨身体纹样作为独立的暂缓实验保留：

| 部分 | 作用 | 组合规则 |
| --- | --- | --- |
| 几何外形 | 身高、体型、头脸和肢体比例 | 在材质渲染前解析 |
| 皮肤第1层：基础毛色 | 将原始毛发响应迁移到一种全身目标色 | 在原始3D材质纹理上使用冻结的 V9 相对明暗方法 |
| 皮肤第2层：局部异色 | 最多给两个已批准语义区域换色 | 使用相同的局部相对明暗迁移，禁止纯色覆盖 |
| 皮肤第3层：安全局部标记 | 一个额头符号、腮红、雀斑、痣或爱心 | 可选、总共最多一个，只能落在允许的安全区 |
| 暂缓层：身体纹样 | 连贯跨过后脑、后背和四肢分支的纹样 | 多视角连续性达到标准前，正式候选禁用 |

身份细节保护区对所有皮肤层都是硬约束：眼睛、鼻子、嘴、口鼻部、明确的物种白色细节区和其他
已审阅排除区，不能被自由程序化位置命中。

## 创建输入与四个外貌问题

物种、准确年龄和性别是生成输入，不是装饰选项。物种强影响模型、比例、区域和颜色权重；年龄强
影响生长和幼体比例；性别只对成年几何提供很弱的生物学先验，绝不选择颜色或标志。

| 产品问题 | 目标选项 | 答案控制什么 | 当前状态 |
| --- | --- | --- | --- |
| 身高 | 偏矮 / 标准 / 偏高 / 随缘 | 结合生长阶段的总身高，并联动胳膊和腿长 | 已通过骨骼/整体缩放部分生效 |
| 体型 | 偏瘦 / 标准 / 圆润 / 随缘 | 胸、腰、腹、胯和四肢粗细 Morph | GLB 没有所需 BlendShape，目前视觉上未生效 |
| 头脸 | 柔和 / 均衡 / 分明 / 随缘 | 头部大小、眼睛比例、脸颊丰满度和口鼻比例 | 头骨缩放可用；完整脸型尚未实现 |
| 外貌标志 | 暖色 / 有标记 / 耳部突出 / 随缘 | 暖色毛发倾向、一个安全局部标记或更明显的耳部变化 | 当前发布词汇已接通；不包含跨身体纹样 |

在体型和完整脸型资产缺失时，产品不能把它们展示成已经有效。基础毛色独立生成，不由标志繁简
选项决定。

### 几何规则

身高是连续结果，不是四个固定值：

```text
身高 = 物种基准
     + 连续年龄生长量
     + 用户身高倾向
     + 很弱的成年性别先验
     + 有界个体差异
```

- 相对物种标准成年体，最终身高缩放限制在 `0.82–1.18`。
- 幼年阶段的生长差异最大，并按阶段内准确年龄连续计算；阶段边界不能产生突然跳变。
- 偏矮、标准、偏高只是偏向当前年龄有效范围的低、中、高分位，不强制一个固定缩放值。
- 成年性别先验很弱，身高约为 `±2.5%`；幼年进一步减弱。它不能决定颜色、区域、标志或微标记。
- 幼体相对头大、四肢短，随年龄连续收敛到成年比例；手、脚、尾巴等附肢变化保持有界并相关，
  不能在轮廓上产生脱节。

## 当前生效的皮肤层

### 1. 基础毛色

Shader 通过 UV 读取 GLB 原始材质纹理，在动画3D表面直接执行冻结的 V9 相对明暗迁移。它保留原始
毛发明暗差异、深色身份细节和已审阅亮部行为。禁止截图后处理，也禁止再出现第二套换色实现。

### 2. 十三个语义区域

前13个区域的位置保持不变。最多选择两个可染色区域；启用两个时，`85%` 使用同一个异色，剩余
`15%` 使用预先批准的兼容配色。

| ID | 区域 | 允许操作 |
| ---: | --- | --- |
| 0 | 头顶毛簇 | 染色 |
| 1 | 额头标志安全区 | 仅外星符号 |
| 2 | 双耳主体 | 染色 |
| 3 | 双耳尖 | 染色 |
| 4 | 双侧脸颊毛 | 仅腮红、雀斑或痣 |
| 5 | 胸口毛簇 | 染色或爱心 |
| 6 | 腹部中心 | 仅爱心 |
| 7 | 双前臂与手/爪 | 染色 |
| 8 | 双肘后侧圆斑 | 染色 |
| 9 | 双小腿与脚 | 染色 |
| 10 | 双膝前侧圆斑 | 染色 |
| 11 | 尾尖 | 染色 |
| 12 | 尾巴下侧 | 染色 |

可染色 ID 为 `0、2、3、5、7、8、9、10、11、12`。默认异色数量分布为
`40%不启用 / 45%一个 / 15%两个`。

### 3. 安全局部标记

当前发布总共支持一个标记：候选可以拥有一个额头符号，或者一个微小标记；在双标记组合完成
视觉审核前，两者暂时互斥。额头符号包括月牙、S符号、双螺旋、星座、彗星、异星符文、菱形、
星星、闪电、波浪和光环。微小标记包括：

| 标记 | 位置和形状 | 颜色规则 |
| --- | --- | --- |
| 腮红 | 双颊柔和晕染，禁止硬边白色圆饼 | 柔桃色或灰粉色 |
| 雀斑 | 双颊三至五个小点 | 暖棕或玫瑰棕 |
| 痣 | 单侧一个极小圆点 | 栗棕或烟炭色 |
| 爱心 | 胸口或腹部一个小符号 | 兼容的玫瑰色或标志色，不发光 |

## 已验证颜色范围

当前发布只使用已经完成视觉审核的每物种10种毛色。狗使用雪白、象牙、奶油、蜂蜜金、杏色、
赤褐、栗棕、巧克力、银灰和烟炭；狐狸使用象牙、奶油、香槟、金色、橘红、狐红、栗棕、深貂棕、
银灰和烟黑。局部异色与标记只能从各物种配置的白名单选择。蓝、紫、青及发光色需要另做多视角
颜色审核，本次发布不声称支持。

## 稳定性与五候选差异

身体比例、颜色、区域选择和局部标记只在创建时生成一次，并与不可变外貌来源一起
保存。Shader 随机数必须稳定：角色做动作、进入正式世界或完成领养后，纹样不能游走、闪烁或改变。

五候选不是五次无约束独立抽签，而是按可见距离筛选：拒绝相同外观 Key，并在用户选择的风格
范围内拉开主色、轮廓、局部异色和安全局部标记。

## 暂缓的跨身体外星纹样

已保留的实验使用预先绘制的1:2纹样画布、按物种裁切的后半身体区域，以及头/肩/胯分段锚点，
最后烘焙回原始 UV。背面效果已有方向，但侧面上臂和大腿出现明显拉伸、截断和横向碎线。根因是
画布本质上仍通过二维身体投影映射，没有真正连续的四肢局部坐标或三维解剖路径坐标。

本次发布不生成、不解析，也不让 `ActorAppearance` 消费身体纹样参数。文字实验结论继续作为参考，
重复 Shader 实验脚本和画布已在正式收口时删除。以后重新启用时，必须重新实现基于解剖路径/UV
烘焙的方案，并通过狗和狐狸的正面、四分之三侧、侧面、背面、俯视验收；不得改动已冻结的 V9
换色和13个正式区域。

## 验收顺序

1. 通过正式 `ElfieActor.configure()` 渲染链路验证狗和狐狸的 V9 换色、13区、局部标记和几何。
2. 验证准确年龄生长与弱性别先验，同时保留有界的个体差异。
3. 在真实 Godot World 中验证持久一致性，并用隔离数据完整走通领养，取得真实前端五个明显不同
   候选的截图。

性能优化作为后续独立工作，不得替代这些视觉验收门。
