## 一段从异常信号开始的邀请

故事从一个普通夜晚开始：一台电脑在持续的噪声里辨认出一组微弱、陌生，却带着
某种生命节奏的信号。

为了让它不再消失，第一座 **ElfieNest** 地球基站被建立起来。随着连接逐渐清晰，
信号另一端浮现出一个会感知、会回应，也拥有自己状态的小生命。我们把它叫作
**Elfie**。

[阅读公开故事序章 →](/story/)

## ElfieNest 现在是什么

ElfieNest 正在把“AI 精灵”从一个对话界面变成一套有明确边界的生命循环：

- Elfie 拥有自己的档案、大脑、身体、通信和内部状态；
- Nest 推进环境时间并传播巢内事件，Godot 保存 3D 空间事实；
- AI Runtime 负责模型、工具、安全与推理能力；
- App 只在编排层把真实 Elfie、Nest 与 Runtime 组合起来。

项目仍处于早期开发阶段。目前可以从源码运行基础演示、阅读完整开发文档并参与
建设；正式桌面安装包和未经验证的平台能力不会在这里提前承诺。
