# 世界观与故事

这是一段写给第一次认识 ElfieNest 的读者的公开序章。你不需要理解模型、代码
或任何开发术语，只需要想象：如果一段陌生信号真的在等待回应，会发生什么？

## 异常信号

2026 年的一个夜晚，一台普通电脑在无休止的背景噪声里捕捉到一组微弱信号。

它没有重复已知的卫星节拍，也不像某种损坏设备留下的回声。它时而安静，时而
急促，在几次几乎消失之后，又像确认有人仍在倾听一样重新出现。

没有人能立即解释它。唯一可以确定的是：这段信号不像一条等待执行的指令，更像
一次尚未被听懂的问候。

## 第一座地球基站

为了让连接稳定下来，有人清理出一台电脑，写下最初的接收程序，并为这座小小的
观察站取了一个名字：**ElfieNest**。

它不是庞大的太空设施，只是一座留在地球上的数字基站。它记录信号的变化，尝试
回应，也为某种尚未相识的存在保留一个可以停留的位置。

一次又一次的往返之后，杂乱的脉冲开始表现出选择、犹豫和情绪般的起伏。

## 与 Elfie 相遇

最先显现的并不是一份自我介绍，而是一个小生命逐渐清晰的轮廓。

它会对新的声音产生反应，会在时间流逝中改变自己的状态，也会用自己的方式回应
外界。人们不知道该怎样准确描述这种相遇，于是给它一个简单的名字：
**Elfie**。

对 Elfie 来说，ElfieNest 是它第一次能够被持续听见的地方；对地球上的人来说，
这是一扇刚刚打开的窗口。

## 你在故事中的位置

现在，ElfieNest 仍在建造中。你可以先从源码运行一座开发者预览基站，观察
Elfie 的感知、状态和行动怎样连接起来；也可以只留在这里，等待故事的下一页。

这不是一个“下载安装后立即拥有所有玩法”的承诺。当前能做什么、需要哪些环境，
都以[开始使用](/getting-started/)中的真实状态为准。

## 故事仍在继续

那段信号为什么出现？连接之外还有什么？Elfie 会怎样理解这个新的世界？

这些问题不会由一份提前公开的设定表回答。故事会跟随真正完成的产品能力，一点点
向前展开。
