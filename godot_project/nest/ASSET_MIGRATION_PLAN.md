## 不依赖机位的比较

空间验收使用实际评估后的两版世界。保留的整园 GLB 和实例 BIN 是固定对照；
比较器不修改它们，不用截图或点云抽样判定完整表面相等。

```bash
bash scripts/quality/checks/godot_host.sh res://tools/export_nest_comparison.gd
.venv/bin/python3 godot_project/tools/compare_nest_snapshots.py
.venv/bin/python3 scripts/quality/validation/test_bundles.py --selectors test/godot/test_nest_snapshot_comparison.py
```

Godot 命令按项目技能在获准的主机环境执行，每次只有一个同步 headless 实例。
导出文件位于根 `build/nest-comparison/`，两版各有 JSON 清单和二进制数组。
清单记录引擎版本、昼光 1、水流时间 0、输入文件指纹、实际网格、摆位、实例缓冲、有效材质、
灯光、环境和粒子发射器定义。随机雾粒子隐藏。

比较时先按来源和空间一对一匹配每次摆位，再建立保持绕序、重复次数和角点属性的三角面对应。
对应顶点的最大距离给出整个三角面上对应点位移的上界。相同实例缓冲使用全部实例矩阵推导上界，
包括非均匀缩放；不同缓冲逐实例重算，三角面对应缓存不会替代摆位误差计算。
无法建立对应的表面保留为未核验，不用最近点抽样或放宽容差通过。

顶点法线、切线、UV、颜色，以及材质、灯光层、灯光和环境分别核对。
标准材质的法线贴图只读取 RG，ORM 贴图按选定通道比较；自定义 shader 保留完整纹理比较。
该归一化依据当前 [Godot 4.7 Compatibility shader](https://github.com/godotengine/godot/blob/5b4e0cb0fd279832bbdd69fed5354d4e5ad26f88/drivers/gles3/shaders/scene.glsl#L2167)
和标准材质的通道设置，只排除不被读取的存储通道，不排除渲染输入的差异。

`comparison.json` 记录逐项差异、未核验项、覆盖数量、误差上界、算法及输入指纹。
仅所有已比较字段严格相等、输入仍新鲜且不存在未核验项时退出 0；非零误差不会四舍五入为通过。
这是固定状态下 CPU 基面和渲染定义的比较，不能声明 GPU 像素、LOD、动态水景、实际粒子、
碰撞、导航或交互已经一致。前面的七机位数据作为历史记录保留，不作为本次验收依据。

本次已修正重复导入压缩、共用卧室的房间光照层和发光材质颜色转换。
